Entry for make.fun's [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) bounty ($2 in USDC).

## The joke

> I banned my cat from my keyboard during work calls, so now he sits on it slower — while holding eye contact.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-line cat joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
The program validates the joke against the competition gate first: 1–200
characters, a single line, not only whitespace. Two runs produce
byte-identical output.
